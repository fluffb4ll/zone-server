# zone-server
Сервер для (пока что) безымянной ММО-игры.

Писался для практического изучения многопоточности в Java. 
Тема вышла достаточно интересная, так что, может быть, рано или поздно я допилю его и напишу клиент игры :)

На данном этапе есть более-менее законченный MVP в ветке [basicDraft](https://github.com/fluffb4ll/zone-server/tree/basicDraft) (да, я сделал фатальную ошибку и назвал ветку общим названием). 
Уже имплементированы симуляция мира по тикам, регистрация и вход через REST API, обмен легковесными пакетами с клиентом через WS (сделано на основе BinaryWebSocketHandler).
